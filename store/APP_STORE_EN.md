## Description
ScreenMotion is an interactive wallpaper playground for iPhone.

Because iOS doesn’t allow realtime gyro live wallpapers like Android, ScreenMotion gives you:
• A buttery **interactive preview** (CoreMotion + touch)  
• **Four themes** — Space, Aquarium, Vehicle, Nature  
• **Vehicle variants** — sports, truck, bike, helicopter  
• **Short video export** to Photos for Use as Wallpaper  
• A clear **how-to** sheet (EN + TR)  
• Optional **sound effects** with mute  

Pick a theme, play with tilt and drag, export, then set from Photos.
