# Store listing assets

Markdown copy for Play Store and App Store (EN + TR).

| File | Use |
|------|-----|
| `PLAY_STORE_EN.md` / `PLAY_STORE_TR.md` | Google Play title, short/full description, keywords |
| `APP_STORE_EN.md` / `APP_STORE_TR.md` | App Store name, subtitle, description, keywords |
| `../assets/store_mock/` | Optional simple PNG mock frames (hero / features / gallery) |

In-app **Showcase** screens on Android (`ShowcaseActivity`) and iOS (`ShowcaseView`) mirror the listing layout for screenshot capture.
